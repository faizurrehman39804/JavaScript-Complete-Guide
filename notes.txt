         if (condition) {

      📖 Definition:
      if else statement me agar condition true ho to if wala code run hota hai, warna else wala code run hota hai.

      💻 Syntax:
      if (condition) {
         console.log("")
      } else {
         console.log("")
      }

      🛠️ Example:
      let age = 16;

      if (age >= 18) {
         console.log("Adult");
      } else {
         console.log("Not Adult");
      }

      ager 18 sa kame ha tho deskount 30% orrr agar 18 sa above ha tho per 
      10% deskount ha .
   --------------------------------------------------

      📖 Definition:
      else if multiple conditions check karne ke liye use hota hai.

      💻 Syntax:
      if (condition1) {
         // code
      } else if (condition2) {
         // code
      } else {
         // code
      }

      🛠️ Example:
      let marks = 70;   

      if (marks >= 80) {
         console.log("A Grade");
      } else if (marks >= 60) {
         console.log("B Grade");
      } else {
         console.log("Fail");
      }

      🛠️ Use:
      - Multiple conditions check karne ke liye
      es na treple satatment use hotha ha 
   --------------------------------------------------
   4️⃣ 📘 Nested if Statement

      📖 Definition:
      Jab ek if statement ke andar doosri if statement use ho to usay nested if kehte hain.

      💻 Syntax:
      if (condition1) {
         if (condition2) {
            // code
         }
      }

      🛠️ Example:
      let age = 20;
      let hasID = true;

      if (age >= 18) {
         if (hasID) {
            console.log("Allowed");
         }
      }

      🛠️ Use:
      - Multiple level conditions ke liye
      - Advanced checking ke liye

      --------------------------------------------------
